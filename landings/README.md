# Landing Pages - Permuta Policial

Landing pages específicas para cada força policial, desenvolvidas com Next.js, React e TailwindCSS.

## 🚀 Instalação

```bash
npm install
```

## 🛠️ Desenvolvimento

```bash
npm run dev
```

Acesse [http://localhost:3000](http://localhost:3000) no navegador.

## 📦 Build para Produção

```bash
npm run build
npm start
```

## 📄 Páginas Disponíveis

- `/app/pm` - Polícia Militar
- `/app/bm` - Bombeiros Militares
- `/app/pc` - Polícia Civil
- `/app/prf` - Polícia Rodoviária Federal
- `/app/pf` - Polícia Federal
- `/app/gm` - Guarda Municipal

**Nota**: Todas as landing pages estão agora no prefixo `/app/` para melhor organização.

## 🎨 Estrutura

```
landings/
├── components/          # Componentes reutilizáveis
├── config/             # Configurações (cores, conteúdo)
├── pages/              # Páginas Next.js
├── styles/             # Estilos globais
└── public/             # Arquivos estáticos
```

## ⚠️ Diretrizes de Compliance

- ✅ Não utiliza símbolos oficiais
- ✅ Não insinua parceria oficial
- ✅ Usa cores inspiradas, sem violar identidade visual oficial
- ✅ Design limpo e profissional
